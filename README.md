# Herramientas del Instituto Séneca

Páginas que se abren en el navegador, sin instalar nada:

- **Generador de UTM:** https://gibemireles.github.io/instituto-seneca/
- **Editor de correos:** https://gibemireles.github.io/instituto-seneca/correos/ — elige plantilla, escribe, revisa y copia el HTML para Brevo o Kommo. Lo que se escribe se guarda solo en el navegador de quien lo usa.

Mantenimiento: Gilberto Mireles. El editor se genera desde el repo de la agencia (`servicios/plantillas-mailing/editor.html`); si cambia allá, se copia aquí como `correos/index.html`.
